# 💼 Cashify

Cashify is a mobile task marketplace application that connects users with small, paid tasks in their local area — such as computer repair, lawn mowing, babysitting, dog walking, and grocery pickup. The platform enables secure task posting, bidding, and online payments.

---

## 🚀 Features
- User authentication
- Task posting and browsing
- Secure online payments (PayPal integration)
- Real-time database updates
- Unit testing and CI integration
